## Sobre

Neste repositório ficam todas as atividades entregues ao longo da disciplina, cada uma em sua própria pasta, com o código-fonte e as instruções para executar.

## Estrutura

```
.
├── atividade-01/
│   ├── README.md
│   └── ...
├── atividade-02/
│   ├── README.md
│   └── ...
└── README.md
```

Cada pasta de atividade segue o padrão `atividade-NN` e tem um `README.md` próprio com o enunciado resumido e como rodar.
